# Documentation

This folder is the working documentation set for Enterprise GIS.

## Goal

Enterprise GIS is being built as a modern, self-hosted web GIS platform with a product ambition closer to Mapbox Studio, ArcGIS Online, and ArcGIS Pro editing workflows than to a basic web map viewer.

The documentation here is organized around that goal:

- product intent and scope
- current implemented capabilities
- engineering architecture and subsystem behavior
- local Docker operations and safe developer workflows
- roadmap direction for the next implementation passes
